# Тестовые данные

- `e2e/` — тестовые клипы для сквозного самотеста и канарейки: постановочное падение
  (`fall_staged.mp4`), дым, проход в красную зону. **Предоставит команда** (SPEC.md §11, §13.9) —
  синтетические ролики здесь не подменяют реальные.
- `images/` — эталонные изображения для smoke-тестов моделей в `qoima doctor`.

На Фазе 0 каталоги пусты: клипы нужны начиная с Фазы 1 (`qoima sim`).
