# Персональные данные и сроки хранения

> Черновик для заказчика. Юридическую часть (основания обработки, уведомление сотрудников,
> соответствие законодательству РК о персональных данных) заказчик согласует со своим юристом.

## Где хранятся данные

Все данные остаются на сервере предприятия. Внешних исходящих соединений по умолчанию нет:
внутренняя сеть сервисов изолирована (`internal: true`), телеметрия Qdrant и Grafana отключена.

| Данные | Где | Срок по умолчанию | Настройка |
|---|---|---|---|
| Клипы инцидентов (−15/+15 с) | `/var/lib/qoima/clips` | 30 дней | `storage.clips_retention_days` |
| Ключевые кадры и снапшоты | `/var/lib/qoima/frames` | 30 дней | `storage.frames_retention_days` |
| Датасеты для обучения | `/var/lib/qoima/datasets` | 365 дней | `storage.datasets_retention_days` |
| События, инциденты, фидбек | Postgres | без ограничения (Фаза 9: архивация) | — |
| Аудит-лог действий и вызовов агентов | Postgres, только добавление | без ограничения | — |
| Метрики (без изображений) | Prometheus | 30 дней | `--storage.tsdb.retention.time` |
| Пароли камер, токены | `.secrets/` (каталог 700) | до замены | — |

Непрерывная запись видео не ведётся: в оперативной памяти хранится только кольцевой буфер
сжатого видео за последние 60 секунд, из которого вырезается клип при событии (SPEC.md §5.2).

## Меры защиты

- Доступ к интерфейсу — по TLS; роли `operator`, `shift_lead`, `site_admin`, `qoima_engineer`
  (RBAC — Фаза 1). Все действия пишутся в неизменяемый аудит-лог.
- Секреты не попадают в git, логи и интерфейс (маскирование в логах проверяется тестами).
- Перед сохранением кадров в датасет лица размываются (Фаза 6); доступ к датасетам — по ролям.
- Комментарии операторов используются как данные, а не как команды для ИИ.

## Что обрабатывается ИИ

Локальная модель (VLM) получает только вырезанные фрагменты кадров вокруг события (ROI), а не
весь кадр и не архив (Фаза 4). Модели и данные не покидают сервер.
