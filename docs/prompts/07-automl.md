Фаза 7 — AutoML-граф на одной RTX 5070 Ti (16 ГБ)

Прочитай CLAUDE.md; SPEC.md §2 п. 5, §4.1 (на одной карте обучение — только в окне обслуживания
и с вытеснением), §9.1 пп. 5–9, §9.2, §12 (Фаза 7); docs/prompts/README.md.

На карте постоянно работают hot path и VLM — для обучения места нет.

Главное решение под 16 ГБ — запиши его в docs/ASSUMPTIONS.md:
- Обучение, авторазметка и экспорт в TensorRT идут только в окне обслуживания, когда VLM
  выгружен. Выгружай sleep-режимом движка, если он есть в нашей версии (проверь по
  документации); иначе — остановкой контейнера llm.
- На это время арбитр выключен: события серой зоны уходят без арбитража (fail-open). В UI баннер
  «Арбитр выключен на время обучения до ЧЧ:ММ».
- Hot path работает всегда. Растёт его задержка — обучение ставится на паузу с чекпоинтом (SPEC).
- Окно и бюджет GPU-часов — в конфиге, включает администратор.

Сначала покажи план и жди моего подтверждения. Если для демо-задачи нет данных — остановись и
попроси.

1. **worker-gpu.** Потребители задач из Valkey Streams. Для обучения — отдельный образ с PyTorch;
   лицензии — через гейт, версии — в lock.

2. **Граф LangGraph из §9.2** с чекпоинтами в Postgres:
   architect → [человек подтверждает спецификацию] → data_miner → autolabel → labeling_critic →
   [человек: golden set ≥ 200] → train → evaluate → не больше 3 повторов → export →
   parity_and_capacity → shadow_deploy → [человек нажимает «Выкатить»] → active.
   - Каждый узел показывает прогресс в UI «Задачи обучения», любой можно остановить.
   - LLM в узлах пишет только текст спецификации и отчётов; всё остальное — код.

3. **Architect на компактном VLM.** TaskSpec по схеме, с честной оценкой реализуемости
   (например, FPS камеры против скорости процесса). Спецификацию подтверждает человек.

4. **Авторазметка.**
   - SAM 3 — только если его лицензия подтверждена как разрешённая; скорее всего нет, проверь.
     Иначе Grounding DINO + SAM 2 (Apache-2.0). После проверки лицензии разрешаю скачать веса.
   - Модели авторазметки грузятся по очереди и не одновременно с обучением. Замерь память
     каждой на этой карте.

5. **Обучение.**
   - RF-DETR для детекции, сегментации и ключевых точек — проверь лицензию каждого размера весов
     (у крупных она бывает другой). Для аномалий — anomalib PatchCore или EfficientAD.
   - Размер модели и батч подбирай по замеру свободной памяти в окне: ≈ 10–11 ГБ на
     Linux-сервере без монитора, на WSL меньше.
   - bf16/AMP, накопление градиентов, чекпоинты для паузы. Бюджет — в конфиге.

6. **Оценка — только на golden set.**
   - Метрики: F1 macro и micro, ROC-AUC, Brier, detection-ECE, бутстрап-интервалы.
   - Temperature scaling; T_low и T_high — с учётом ёмкости VLM из плана.
   - Стресс-тесты: шум, расфокус, блики, пыль, ночь.
   - Без golden set граф дальше не идёт (тест).

7. **Deployer — детерминированный код.**
   - ONNX → TensorRT на этой карте, parity-тест ONNX против TRT, бенчмарк.
   - Проверка, что модель влезает в план мощности. На 16 ГБ новая модель отнимает видеопамять у
     VLM — покажи в отчёте, какой профиль VLM останется. Решает человек.

8. **Triton.**
   - Замерь, сколько видеопамяти занимает пустой Triton и Triton с одной моделью. Если для 16 ГБ
     это дорого — покажи мне цифры и варианты; архитектуру (в SPEC — hot-load через Triton) сам
     не меняй.
   - config.pbtxt строится из шаблона. Модель загружается в shadow на shadow_days. «Выкатить» и
     «Откатить» — одной кнопкой.

9. **create_monitoring_task в чате** запускает граф — с подтверждением человека.

Демо-приёмка (по SPEC) на задаче «каска / без каски»:
- Нужны ролики или кадры с касками и без — с объекта или из открытого датасета с разрешённой
  лицензией. Список кандидатов покажи мне; без меня данные не бери.
- Сквозной прогон: от запроса в чате до модели в shadow.
- Без golden set граф останавливается.
- Parity-тест ловит испорченный движок.
- Во время обучения алерты о падении и дыме идут (fail-open, тест), hot path в SLO.
- После окна обслуживания VLM возвращается сам.

Отчёт:
- память и время каждого шага на этой карте;
- метрики демо-модели;
- размен видеопамяти с VLM;
- что не проверено и что нужно от меня.

Закоммить в main, запушь и остановись.
